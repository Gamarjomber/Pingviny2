# GRA — каркас гри + демка фізики змійки

Phaser 3 + TypeScript + Vite. Симуляція окремо від рендера.

```
npm install
npm run dev        # розробка
npm test           # юніт-тести симуляції
npm run build      # dist/index.html — одним файлом, відкривається подвійним кліком
```

Керування: миша — повертати, A/D або ←/→, Пробіл — ривок, Shift — гальмо, Q — дебаг, K — урон коту, E — вороги, R — рестарт, Tab — панель.
Підібрати впалого кота або відчеплену групу — торкнутись головою.

## Структура

| Папка | Що там | Залежить від Phaser |
|---|---|---|
| `src/core` | математика, ГВЧ із seed, шина подій, стек множників, фіксований крок | ні |
| `src/data` | усе змістове: конфіг змійки + схема тюнінгу, класи котів, арена, камера | ні |
| `src/sim` | чиста симуляція: `Sim` (збирає все), `Squad` + `Trail` (ланцюг), `EnemySystem`, `CombatSystem`, рикошет, колайдери | ні |
| `src/input` | `IntentSource` + реалізації (миша/клавіатура; стік і тач додаються тут) | так |
| `src/render` | `SquadView`, `EnemyView`, `CombatView`, `SpriteFactory` (спрайти 16×16), `CameraRig`, `Juice`, світ | так |
| `src/ui` | HP-ланцюжок, панель тюнінгу (DOM) | ні |
| `src/scenes` | збірка модулів у сцену | так |

Правила: симуляція не імпортує Phaser; рендер лише читає стан; симуляція повідомляє про події через `EventBus`
(звук, частинки, трясіння, діалоги підписуються на них); числа лише в `data/`.

Назви в коді за глосарієм ТЗ: Squad, Leader, Tail (chain), Unit, Split, HoldFormation, Rejoin.
Рішення за ТЗ: `docs/DECISIONS.md`.
