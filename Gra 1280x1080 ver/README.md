# GRA — кошача змійка (демо)

**Запустити:** завантажити `index.html` (кнопка Download raw file) і відкрити в браузері. Один файл, інтернет не потрібен.

Керування: миша — поворот, A/D або ←/→, Пробіл — ривок, Shift — гальмо, F — активка Воїна, V — Воїн вкл/викл, Tab — панель налаштувань, E — вороги, R — рестарт.

Внутрішня роздільність 1920×1080 (піксель-арт, коти 64×64).
Вихідний код — у `source/` (`npm install && npm run dev`).
